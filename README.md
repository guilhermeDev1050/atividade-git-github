# Chapa Quente Burguer

Este projeto é um site simples para o Chapa Quente Burguer, desenvolvido para a disciplina de Engenharia da Qualidade e Confiabilidade da UniRV.

## Como Usar o Projeto
1. Clone este repositório em sua máquina local.
2. Abra o arquivo `index.html` em qualquer navegador moderno para visualizar a página principal.
3. Clique em **Pedir** para testar a funcionalidade interativa de pedidos de lanches.
4. Navegue até a página de **Promoções** através do menu superior para conferir as ofertas do dia!
